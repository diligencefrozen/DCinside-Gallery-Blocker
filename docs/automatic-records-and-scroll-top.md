# 자동 기록 가져오기와 디시 상단 이동: 개발 결과

2026-11-16. 기존 7.3.52.2026 개발 작업에 대한 증분 변경이다. manifest 버전은 7.3.51.2026을 유지하며 릴리스 빌드나 스토어 업로드는 수행하지 않았다.

## 사용 흐름

옵션 → 디시 기록 가져오기에서 **디시 차단·메모 자동 불러오기**를 누르면 된다. 사용자가 디시 갤러리, 설정 메뉴, 차단·메모 목록을 직접 열 필요가 없다.

확장이 같은 브라우저에 임시 비활성 탭을 생성해 기록을 읽는다. 진행 막대와 ‘불러오는 중입니다. 잠시만 기다려 주세요’ 안내를 표시하고, 등록 범위 확인 중에는 확인한 범위/전체 범위, 갤러리 수, 기록 건수를 표시한다. 완료하면 중복·충돌·적용 가능·보류 사유를 포함한 미리보기를 만든다. **사용자가 적용하기 전에는 확장의 차단·메모에 저장하지 않는다.** 기본 병합, 기존 메모 유지, 별도 덮어쓰기 선택과 직전 가져오기 되돌리기를 유지한다.

중지 버튼과 오류 처리를 제공하며 임시 탭은 완료·실패·중지 시 닫는다. 옵션 문서를 닫을 때도 생성한 탭 정리를 요청한다. 이미 열려 있던 사용자 탭은 이동하거나 닫지 않는다. 사이트 연결/권한/형식 오류는 완료로 가장하지 않는다.

## 읽는 데이터와 범위

디시 공개 `user_block.js`와 `UserMemo` 구현에서 확인한 **`block_all`, `block_parts`, `user_memo` 세 저장 항목만** 읽는다. 저장소 전체 열거, 인증 관련 항목, 로그인 쿠키·토큰 접근은 없다. 실제 사이트 코드가 사용하는 HTTPS gall 출처와 `/_js/crossDomainStorage.html` 페이지를 사용하며 내부 저장 API를 추정하지 않는다. 코드·URL·해시 근거는 [초기 조사](dc-native-records-development.md)에 기록되어 있다.

`block_parts`의 등록된 모든 갤러리와 `user_memo`의 모든 범위를 순회한다. 메모만 등록되어 있는 갤러리도 포함한다. 전체/갤러리별 범위, 원래 활성 상태, 단어/식별 코드/닉네임/IP와 메모 본문·색상을 보존한다. 미니·인물 접미부는 종류로 구분하고, 저장 형식에 일반/마이너 구별이 없으면 종류를 추정하지 않는다. 두 번의 읽기 결과가 달라지면 재시도를 안내한다. 4MB/20,000건 한도를 넘으면 중지하며 잘린 결과를 적용하지 않는다. 알 수 없는 내부 형식은 사유를 표시한다.

| 항목 | 적용 |
|---|---|
| ON 전역 이용자 차단·단어 | 기존 로컬 v2/키워드 경로에 병합 |
| 전역 메모 | 기존 메모 키에 본문·색상 보존 |
| 자동 수집한 갤러리별 메모 | 원래 갤러리 ID 범위 유지 |
| 갤러리별 차단 | 보류. 전역으로 승격하지 않음 |
| OFF/상태 미확인 차단, 불확실한 식별자, 지원하지 않는 IP 범위 | 사유 표시 및 보류 |

갤러리별 메모는 사이트 자체가 `userMemoData[galleryId]`로 구분하고 별도 갤러리 종류를 저장하지 않는다. 자동 수집은 이 검증된 모델을 `nativeScopeModel:'gallery-id'`로 표시하고 기존 `gallery:<id>:uid/ip:<value>` 키에 저장한다. 미확인 DOM에서 가져온 종류별 메모를 같은 범위로 임의 확정하는 것은 허용하지 않는다. 닉네임을 UID로 바꾸거나 IP 범위를 늘리지 않는다. 필터 ON/OFF는 유지한다.

공식 PC/모바일웹 메모 백업과 붙여넣기는 그대로다. 사용자가 설정 모달을 직접 열어야 하는 DOM 읽기 UI는 제거했다. 자동 수집은 한 번의 독립적인 함수 주입으로 결과를 받도록 구성하여 Firefox의 서로 다른 주입 전역 환경에 의존하지 않는다. DOM 수집 모듈은 과거 형식의 개발 회귀 검사에만 남겨 두었으며 옵션 페이지에 로드하지 않는다.

## 상단 이동 버튼

현재 글의 댓글로 이동하는 버튼과 전체 댓글 수 표시도 추가했다. 후속 변경과 최신 검증 결과는 [활동량·미리보기·읽기 UI 보고서](reading-activity-and-preview-update.md)에 정리했다.

디시 PC 게시판 목록·글보기와 모바일 페이지에서 길게 스크롤하면 우측 하단 **↑** 버튼이 나타난다. 페이지를 읽다가 누르면 페이지 맨 위로, 긴 내부 댓글/목록을 스크롤하다 누르면 해당 영역의 맨 위로 이동한다. 키보드 접근과 동작 줄이기 환경설정을 지원한다.

자동 새로고침 카운트다운, 갤러리 차단 플로팅 컨트롤 및 다른 fixed/sticky UI의 실제 위치를 확인해 그 위에 간격을 두고 배치한다. 이름을 알 수 없는 우측 하단 고정 바도 화면 hit-test로 확인한다. 위치·크기·표시 변경, 화면 크기 변경과 전환 애니메이션에 따라 다시 배치한다. 해당 모서리에 공간이 없으면 컨트롤을 가리지 않도록 버튼을 숨긴다. 기존 컨트롤의 위치·클릭 이벤트·자동 새로고침 동작은 변경하지 않는다.

페이지 scroll 작업은 프레임당 한 번으로 묶고, 일반 DOM 변경은 짧게 모아 처리한다. 플로팅 UI 변경은 즉시 위치 계산을 요청한다. 버튼이 필요하지 않은 상단에서는 후보 검색을 수행하지 않는다. 대상 출처 이외에는 버튼을 삽입하지 않는다.

## 검사와 제한

앞선 자동 가져오기 단계에서는 전체 Node 단위/계약 **51/51 통과**, 전체 브라우저 묶음 **132개 중 128개 통과, 실패 0, 선택적 성능 프로필 4개 건너뜀**이었다. 해당 단계의 추가 관련 검사 **20/20**에는 당시 제공했던 고급 DOM 경로도 포함되어 있다. 현재 UI에서는 이 수동 경로를 제거했으며 후속 결과는 위 최신 보고서에 구분해 기록한다. 검사 브라우저는 Playwright Chromium과 Firefox이며 사용자 Chrome 프로필을 사용하지 않았다.

검사 범위:

- 임의 디시 탭·모달이 없는 상태에서 자동 수집과 진행률, 지원되는 갤러리 메모 보존, 명시적 적용과 undo.
- OFF·전체/갤러리 범위·메모만 있는 갤러리·특수문자·색상, 알 수 없는 형식·빈 데이터·중지·위장 출처.
- 읽기에서 접근하는 키가 지정된 세 개뿐이며 사이트 저장을 수행하지 않음.
- Chromium/Firefox 실제 설치형에서 공개 기록 페이지의 자동 읽기와 임시 탭 정리 확인. 격리된 빈 프로필로 실행하여 실제 계정 기록을 쓰지 않음.
- 양 엔진의 페이지/내부 댓글 상단 이동, 새로고침 버튼 클릭 보존, 기존/동적으로 추가된 플로팅바·이름을 알 수 없는 CSS 고정 바와의 간격, 숨김 후 재배치, 중복 주입 방지.
- 기존 가져오기·파일·메모·필터·자동 새로고침·팝업 기능 회귀 검사.

```powershell
node --test --test-isolation=none tests/*.test.mjs
$env:PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS='1'
node --test --test-concurrency=1 --test-force-exit tests/*.test.cjs
# 공개 사이트 읽기만 수행하는 설치형 추가 검사
$env:DCB_TEST_NATIVE_AUTO_LIVE='1'
node --test --test-concurrency=1 tests/records-installed.test.cjs
```

전체 로그는 `test-results/native-auto/full-browser.log`, 자동 미리보기는 `test-results/native-auto/preview.png`, 상단 이동 화면은 `test-results/site-scroll-top/`에 있다.

자동 수집은 **현재 브라우저 프로필의 HTTPS 디시 PC 저장소** 대상이다. 다른 브라우저·프로필·기기·HTTP 출처·공식 앱에만 있는 기록이나 서버 계정의 전체 목록 조회를 보장하지 않는다. 실제 데이터가 등록된 사용자 로그인 프로필 검증은 남아 있으며, 사이트 저장 형식 변경 시 안전하게 중지하거나 보류한다. 갤러리별 차단 적용은 아직 지원하지 않으며, 확장→사이트 기록 쓰기와 실시간 동기화는 구현하지 않았다. 디시 자체 외부 링크 경고 강제 OFF는 앞선 구현을 유지하고 브라우저 보안 설정은 변경하지 않는다.

추가 확장 권한은 없다. 변경 소스: `src/content/dc-native-records-auto.js`, `src/shared/dc-native-records.js`, `src/content/dc-native-records-collector.js`, `src/ui/options/dc-records-import.js`, `src/ui/options/options.html`, `src/shared/storage/user-block-store.js`, `src/content/tools/scroll-top.js`, `manifest.json`. 관련 테스트와 README·개인정보 안내·릴리스 노트도 갱신했다.
