# 미리보기 댓글 UX — 1단계

## 확인한 원문 계약

2026-10-26 공식 공개 자료를 읽기 전용으로 확인했다.

- [PC 댓글 스크립트](https://gall.dcinside.com/_js/comment.js?v=261021-5): 일반·대댓글 등록, 댓글 조회, 회원·비회원 삭제, Turnstile, reCAPTCHA v2/v3.
- [이미지 CAPTCHA 스크립트](https://gall.dcinside.com/_js/kcaptcha.js): 원래 이미지·입력·갱신 이벤트와 `/kcaptcha/image_v3/`.
- [공통 스크립트](https://gall.dcinside.com/_js/common.js?v=261023): 비회원 비밀번호 저장 및 인증 후 자동 재전송 경로.
- [공개 게시글](https://gall.dcinside.com/board/view/?id=programming&no=1476608): 같은 출처 원문 입력 폼, 실제 보안 이벤트, Cloudflare 인증 요소.

등록은 `POST /board/forms/comment_submit`. `id`, `no`, `memo`, 원문 검증 필드·갤러리 유형·인증값을 사용한다. 대댓글은 검증한 부모를 `c_no`, 클릭한 댓글을 `reply_no`로 보낸다. 조회 JSON의 `no`가 댓글 ID이며 `c_no`는 부모 ID다.

삭제는 `POST /board/comment/comment_delete_submit`. 원문의 `ci_t`, `id`, `no`, `re_no`, `mode=del`, `_GALLTYPE_`, `c_k_v`, `rc_key`와 인증값을 사용한다. 비회원은 원문 삭제 폼의 hidden 필드·`v_cur_t`·`re_password`를 추가한다. `true||...` 응답을 확인한 후 목록을 재조회한다.

## 변경 동작

- 입력창 기본 펼침, 접근 가능한 열기/닫기 토글. 접기·필터·같은 글 갱신 중 원문 iframe과 초안을 유지한다. 자동 펼침은 포커스나 스크롤을 이동하지 않는다.
- 등록 확인 후 본문만 비우고 일반 댓글 모드로 돌아온다. 닉네임·비밀번호와 성공한 비회원 댓글 ID는 현재 미리보기 세션에만 보관하며, 팝업 닫기·다른 글 이동 시 폐기한다. 텍스트 초안만 게시글·답글 대상별 탭 메모리에 보존한다.
- 본문 일반 클릭 또는 답글 버튼으로 같은 입력창을 전환한다. 링크·미디어·선택 영역·작성자 메뉴는 가로채지 않는다. 늦게 로드되는 원문 댓글의 ID·소유권·날짜도 반영한다.
- 로그인은 원문/조회 응답의 본인 삭제 권한, 비회원은 같은 세션에서 등록 확인한 ID를 근거로 삭제 버튼을 표시한다. 삭제 확인·필요 인증·명시적 확인 클릭을 거친다. 실패 시 댓글을 유지한다.
- 원문 이미지 CAPTCHA와 Turnstile 요소를 유지하고, 추가 reCAPTCHA는 사이트 키와 원문 출처의 SDK로 연결한다. 인증 완료 콜백은 상태만 갱신하며 자동 재전송하지 않는다. 다시 누른 등록/삭제 확인 버튼당 쓰기 요청은 최대 한 번이다.
- 비밀값은 확장 메시지·로그·영구 storage에 넣지 않는다. 원문의 자동 재전송/비밀번호 저장 제출 핸들러는 호출하지 않으며, 실제 버튼의 보안 이벤트는 보존한다. 읽기 브릿지는 등록·삭제 주소를 모두 거부한다.
- 원문 날짜를 `YYYY.MM.DD AM/PM hh:mm:ss`로 표시한다. 시간대가 명시된 값은 Asia/Seoul로 변환한다. 시각만 주어진 경우 원문 DOM의 전체 날짜를 우선 보완하며, 끝내 확인되지 않으면 원문 값만 유지한다.
- 댓글 작성자 영역에만 기존 폭 축소 처리를 제외하고 메타 정보를 개행한다. 고정 iframe 높이 대신 실제 입력·인증 영역 높이를 반영해 빈 공간과 중첩 스크롤을 제거한다.

## 테스트 결과

| 명령 | 결과 |
| --- | --- |
| `node tests/preview-compose.test.cjs` | Chromium 모의 서버 27개 시나리오 통과 |
| `node tests/preview-performance.test.cjs` | 통과 |
| `node --test tests/preview-contextmenu.test.mjs` | 1개 통과 |
| `node --test --test-timeout=45000 tests/preview-regression.cjs` | 1100px 가로 넘침 검사 통과 후 기존 차단 안내 문구 기대값 불일치에서 실패 |
| 변경 JavaScript `node --check`, `git diff --check` | 통과 |

27개 시나리오는 네 갤러리 유형, 기본 펼침/토글, 연속 작성, 일반·대댓글·대댓글의 답글, 초안/자격정보 수명, 본인 삭제/실패, 삭제 CAPTCHA, 이미지 CAPTCHA 갱신, v2 만료·v3·Turnstile, 링크/선택/키보드, 비동기 원문 댓글 로딩, 360/540/1100px, 날짜 경계, 중복 클릭, 늦은 응답, 메시지 검증을 포함한다. 모의 인증 토큰으로 제어 흐름을 검증했으며 실제 인증 통과 증거는 아니다.

회귀 실패: 실제 문구 `ⓘ 차단 설정으로 댓글 1개 숨김`, 기대 문구 `차단 설정에 따라 댓글 1개를 숨겼습니다.`. 이번 수정에서 해당 차단 안내 문구는 변경하지 않았다. 테스트가 이 지점에서 중단되어 이후 검사까지 통과했다고 주장하지 않는다.

## 실사이트 검증과 미확인 사항

| 기능/환경 | 실서버 확인 범위 |
| --- | --- |
| 공개 비회원 원문 폼 | 실제 Chromium에서 360/540/1100px 표시 확인. 입력 폼 높이 296px, 가로 넘침·iframe 내부 스크롤 없음 |
| Turnstile | 실제 Cloudflare 체크박스가 본문 아래·등록 버튼 위에 표시됨. 사용자의 인증 완료 및 등록은 미검증 |
| 회원 댓글 작성/삭제 | 계정으로 실제 요청하지 않음. 모의 통합 테스트만 통과 |
| 비회원 연속 댓글/대댓글/삭제 | 실제 쓰기 요청하지 않음. 모의 통합 테스트만 통과 |
| 이미지 CAPTCHA·추가 reCAPTCHA·보호 댓글 | 공식 스크립트 계약 및 모의 성공/실패 흐름 확인. 해당 조건의 실서버 인증 완료·등록·삭제는 미검증 |
| Firefox·모바일 원문 | 미검증. 360/540px 검사는 PC 원문을 사용하는 Chromium 뷰포트 검사 |

실사이트 검사는 등록/삭제 경로를 브라우저 라우팅에서 차단하고 수행했다. 쓰기 시도와 실제 쓰기 모두 0회다. 화면 증거는 로컬 `test-results/preview-comment-live-{360,540,1100}.png`에 있다(테스트 산출물, Git 제외).

비회원의 과거 댓글은 소유권을 추정하지 않아 삭제 버튼이 없다. 날짜가 원문·응답 모두에 없는 댓글은 날짜를 만들지 않는다. 공유 댓글 스트림 등 계약을 확인하지 못한 경우에는 원문 확인 안내를 유지한다. 실제 인증 완료부터 서버 등록·삭제까지의 필수 종단 검증은 남아 있다.
