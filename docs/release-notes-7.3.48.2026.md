# 7.3.48.2026 릴리스 후보

## 변경 사항

- 신규 설치에서 작성자 우클릭 동작의 기본값을 `contextMenu`로 변경했습니다. 저장된 `instant`와 `contextMenu` 값은 그대로 유지하며, 값이 없는 경우에만 새 기본값을 기록합니다.
- `access-guard`가 평문 갤러리 ID와 `id=...` 입력을 URL로 잘못 해석하지 않도록 정규화 순서를 고쳤습니다.
- 동일한 차단 URL에서 설정 변경이나 중복 실행이 발생해도 안전 페이지 이동을 반복 예약하지 않도록 보호했습니다.
- 사용자 차단 OFF 상태의 `차단됨 · 해제` UI와 복수 토큰 해제 로직은 유지했습니다.

## 검증

- 번들 Node 런타임으로 변경 파일 문법 검사 통과.
- 신규 7.3.48 계약 테스트 2건 통과.
- 기존 단위 테스트 전체는 33건 중 26건 통과, 7건 실패했습니다. 실패 원인은 기존 계약/런타임 환경 의존 항목으로 분류했으며 이번 패치에서 테스트를 삭제하거나 기대값을 숨기지 않았습니다.
- Playwright 미리보기 테스트는 Chromium 실행 파일이 호스트에 없어 실행하지 못했습니다.
- `scripts/package-extension.mjs`로 `dist/DCinside-Gallery-Blocker` 설치용 폴더를 생성했습니다.

## 제한 사항

실제 Chrome/Firefox 설치 업데이트, 구형 하드웨어 장시간 프로파일, Google 검색에서 30초 이상 본문 열람 시나리오는 이 실행 환경에서 브라우저 바이너리와 대상 사이트 접근을 확보하지 못해 미측정입니다.
