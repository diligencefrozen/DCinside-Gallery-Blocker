갈등 표현 감지

현재 화면에 보이는 게시글·댓글의 문장을 기기 안에서 분석합니다. 설정에서 켜야 작동하며, 원문을 숨기거나 이용자를 차단하지 않습니다.

표시를 읽는 방법

  • 댓글의 갈등 표현 주의, 게시글의 갈등 표현 참고는 자동 분류 참고 표시입니다. 작성자의 정체·국적·소속·의도를 입증하지 않습니다.
  • 오탐과 누락이 있을 수 있습니다. 표시가 없다는 사실도 정상 판정을 뜻하지 않습니다. 민감도를 높이면 표시와 오탐이 함께 늘 수 있습니다.
  • 모델은 제목과 댓글을 입력으로 사용합니다. 게시글 본문 분석은 추가 검증이 필요한 실험 기능입니다. 제목과 본문을 합쳐 최대 256토큰까지 분석하므로 긴 글의 뒷부분은 제외될 수 있습니다.
  • 화면에 로드된 본문과 댓글만 분석하며, 목록의 모든 게시글을 가져오거나 계정 이력을 수집하지 않습니다. 짧은 문장과 디시콘만 있는 댓글은 건너뜁니다.

데이터 처리

분석 대상은 페이지 제목과 문장입니다. 닉네임·아이디·IP를 모델 입력에 추가하지 않습니다. 원문과 점수는 기기 메모리의 제한된 임시 캐시에만 보관하며 외부 분석 서버로 보내지 않습니다. 켜기·대상·민감도 설정은 Chrome Sync에 저장됩니다. 최초 모델 준비에는 시간이 걸리고 메모리를 사용할 수 있습니다.
