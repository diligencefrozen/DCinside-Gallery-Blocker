🧪 공격적 표현 감지 · 기기 내 AI 실험 기능

지금 보고 있는 게시글과 댓글에서 공격적·모욕적·위협적 표현을 찾아 접어 줍니다. 이 기능은 설정에서 직접 켜야 사용할 수 있습니다. 가려진 내용이 궁금하면 이번만 보기를 눌러 다시 볼 수 있습니다.

어떻게 작동하나요?

  • 공격적인 표현이 감지된 댓글이나 게시글은 내용을 바로 보여 주지 않고 먼저 가려 둡니다. 필요하면 이번만 보기를 눌러 원문을 확인할 수 있습니다.
  • 감지 결과가 항상 정확한 것은 아닙니다. 문제가 없는 글이 가려지거나, 반대로 공격적인 표현을 놓칠 수도 있습니다. 이 결과만으로 작성자의 성향이나 글을 쓴 의도를 단정하지 않는 것이 좋습니다. 작성자의 성격·신원을 판단하거나 신고·계정 조치를 수행하는 기능도 아닙니다.
  • 감지 수준을 높이면 더 많은 표현을 찾아냅니다. 대신 문제가 없는 글까지 가려질 가능성도 함께 높아집니다.
  • 댓글 감지를 기준으로 만든 기능입니다. 게시글 본문 감지는 아직 시험 중이며, 글이 아주 길면 앞부분만 확인할 수 있습니다.
  • 지금 화면에 불러온 게시글과 댓글만 확인합니다. 게시글 목록을 따로 수집하거나 사용자의 과거 활동을 찾아보지 않습니다. 내용이 거의 없는 짧은 댓글이나 디시콘만 있는 댓글은 검사하지 않을 수 있습니다.

개인정보는 어떻게 처리하나요?

글과 댓글은 이 기기 안에서만 확인하며 외부 분석 서버로 보내지 않습니다. 닉네임, 아이디, IP 같은 작성자 정보도 공격적 표현을 찾는 데 사용하지 않습니다.

현재 버전은 검증된 모델·토크나이저·실행 엔진을 확장 프로그램에 함께 포함합니다. 임의의 원격 ONNX 그래프나 실행 코드를 내려받지 않습니다. 따라서 모델만 별도로 설치하거나 삭제하는 기능은 제공하지 않으며, 기능을 끄면 로컬 분석 런타임과 DOM 검사, 추론 캐시를 시작하지 않습니다.

검사 과정에서 필요한 내용은 잠시 메모리에 보관될 수 있지만 계속 저장하지 않습니다. 기능을 켰는지, 댓글과 게시글 중 무엇을 검사할지, 감지 수준은 브라우저 확장 프로그램 설정에 저장됩니다.

처음 기능을 사용할 때는 검사 기능을 준비하는 데 시간이 조금 걸릴 수 있으며, 사용하는 동안 평소보다 메모리를 더 사용할 수 있습니다.
