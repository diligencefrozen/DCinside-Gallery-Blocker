# 미리보기 준비 상태와 가독성 개선

## 변경 내용

- 본문, 댓글 조회, 네이티브 댓글 작성 도구 준비 상태를 각각 안내한다. 실제 유지보수 중이라는 오해를 피하도록 ‘정비 중’ 대신 ‘준비하고 있어요’를 사용한다.
- 준비 안내에 작은 점 세 개의 CSS 모션을 적용한다. 완료·실패 시 사라지며, 탭 숨김과 `prefers-reduced-motion`을 지원한다. 추가 타이머, 네트워크 요청, DOM 감시자는 없다.
- 댓글이 없거나 조회에 실패한 경우 정적인 안내와 다음 행동을 표시한다. 본문 로딩 중에도 닫을 수 있다.
- ‘댓글 쓰기’ 버튼을 구분하고 보조 설명·날짜 대비를 높인다. 기존 밝은/어두운 테마, 댓글 구조, 네이티브 작성폼, 초안 및 하이버네이션 동작을 유지한다.
- 버전, 저장 데이터, 권한 변경 없음.

## 변경 파일

- `src/content/core/content_script.js`: 상태 카드, 모션, 접근성, 표시 문구와 CSS.
- `tests/preview-ux.test.cjs`: Chromium/Firefox 준비·실패 상태, 색상 대비, 동작 줄이기, 탭 숨김, 모바일 폭, DOM 안정성 및 스크린샷.
- `tests/preview-compose.test.cjs`: 기존 작성폼 대기 조건을 새 문구에 맞춤.
- 이 문서.

## 검증

Windows의 Playwright 실제 Chromium/Firefox 엔진에서 합성 문서와 로컬 모킹 응답으로 실행했다. 실제 서비스 로그인·댓글 등록을 수행한 검증은 아니다.

| 명령 | 결과 |
| --- | --- |
| `node --check src/content/core/content_script.js` 및 변경 테스트 문법 검사 / `git diff --check` | 통과 |
| `node --test --test-concurrency=1 tests/preview-ux.test.cjs tests/preview-activity-layout.test.cjs` | 14 통과, 0 실패, 선택적 프로파일 4 건너뜀 |
| `node tests/preview-compose.test.cjs` | 기존 88 시나리오 통과 |
| `node tests/preview-regression.cjs` | 미디어·필터·반응형·포커스·닫기 회귀 통과 |

준비 안내 보조 텍스트 대비는 두 테마 모두 4.5:1 이상이다. 250ms 관찰 중 안내 카드 DOM 변경은 0회, 댓글 로딩 중 작성폼 iframe 생성은 0개, 테스트 중 등록/삭제 요청은 0회였다. 390px 화면에서 가로 넘침이 없고 실패 시 모션이 사라진다. 기존 대량 댓글 점진 렌더링·조회 대기 취소·반복 장식 휴면 테스트도 통과했다.

스크린샷은 `test-results/preview-ux/`, 로그는 `test-results/preview-ux-{regression,composer,media}.log`에 보관한다. 밝은 댓글 준비 화면, 어두운 작성폼 준비 화면, 모바일 댓글 화면을 직접 확인했다.

이번 변경은 상태 표시 개선으로, 서버 응답시간 또는 스크롤 프레임 속도 향상을 주장하지 않는다. 관련 회귀로 범위를 검증했으며 전체 테스트와 성능 벤치마크는 중복 실행하지 않았다. 실제 사이트 인증·쓰기와 사용자 고유 테마 조합은 별도 실사용 확인 범위다.

## 적용 및 되돌리기

설치용 ZIP을 새 폴더에 풀고 확장프로그램을 다시 로드한 뒤 갤러리 탭을 새로고침한다. 설정 초기화는 필요하지 않다. 문제가 있으면 이전 설치 폴더를 다시 로드한다. 저장 스키마 변경이 없어 데이터 역변환은 필요하지 않다.
